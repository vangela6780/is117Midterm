# Archived Workstreams

This directory stores retired or completed workstreams that are no longer active.

## Purpose

- preserve historical decision records
- keep `docs/_specs/` focused on active work
- support post-implementation audits

## Archive Move Rule

Move a workstream from `docs/_specs/<workstream>/` to `docs/_archive/<workstream>/` when:

- all planned sprints are complete, and
- implementation QA has passed, or
- the workstream is explicitly retired
